# Focus Timer

Personal Android productivity timer.

## Features
- Fixed focus sessions: 15, 25, 30, 45, 60 minutes
- Portrait-only dark interface
- Optional Airplane Mode settings prompt before a session
- Full-screen countdown
- Motivational focus prompts every 2 minutes
- Hold for 3 seconds to end a focus session early
- Red completion screen
- Optional 5-minute break timer
- Settings for motivational prompts, sound, vibration, and keeping the screen awake

The app does not directly toggle Airplane Mode. Android restricts this for ordinary apps, so the app opens the relevant system settings screen instead.
